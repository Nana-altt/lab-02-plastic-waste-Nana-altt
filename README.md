# Plastic Waste Tracker

This project is a simple static web page about reducing plastic waste and tracking everyday habits.

## Overview
- Learn about common plastic waste problems
- See reduction tips
- Explore a quick impact tracker

## Run it locally
Open `index.html` in any browser.

## Files
- `index.html` — page layout
- `styles.css` — styling
- `script.js` — small interactive behavior
